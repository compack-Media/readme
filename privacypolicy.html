1. Personal Information We Collect or Receive

To ensure app stability, fix crashes, improve performance, and provide ads, we may use analytics and advertising tools to process necessary information (the “Analytics Information”).

Information Collected Automatically

Log Information: Includes IP addresses, advertising identifiers (such as Android ID, OAID, IDFA, etc.), operating system version, timestamps, usage history, crash reports, page clicks, and actions. Uses include monitoring app operation, diagnosing errors and crashes, and improving performance and stability.

Device Information: Includes hardware model, operating system, IP address, language, time zone, device settings, and advertising identifiers; used to identify devices, support features, optimize the experience, ensure security, and prevent fraud.

Usage Information: Includes access times, feature usage, preferences, session duration, and page navigation paths; used to analyze user experience, improve features, and fix issues.

The App’s Media Processing and Local Task Records

After a user selects an image or video, the App reads the information needed for processing on the device (for example, the file name, format, size, dimensions, video duration, and output settings), performs compression, conversion, or enhancement locally, and writes the result to the system media directory. The current client does not have a feature that uploads original media or exported files to servers owned by the operator through media processing. The app stores task records locally on the device; fields may include media type, file name, input/output size and format, output URI, task type, creation/completion time, status, progress, and error information.

Third-Party Sources

We may receive information from third parties that provide analytics, advertising, or security services, or collect information through their tools:

  • Firebase / Google Analytics: Used to analyze usage, understand user needs, and improve the service.
  • Advertising Platforms: Google AdMob; Facebook Audience Network, AppLovin. These platforms may collect device information, usage data, and advertising-related data through their tracking technologies. Each platform processes information under its own privacy policy.
  • Subscriptions and Payments: Payments are processed through Google Play in-app billing.
